캐릭터 데이터 추가 방법

characters.json 파일에 캐릭터 정보를 추가한 뒤 GitHub 저장소에 반영하면 됩니다. 이미지 파일은 images/ 폴더에 넣고, image에는 파일 경로를 적습니다.

{"id":"yuuka","name":"하야세 유우카","school":"밀레니엄","type":"student","image":"images/yuuka.webp"}

각 캐릭터의 id는 서로 달라야 합니다. 이미지가 없으면 이름이 대신 표시됩니다.
